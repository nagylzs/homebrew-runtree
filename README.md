# Nagylzs Runtree

## How do I install these formulae?

`brew install nagylzs/runtree/<formula>`

Or `brew tap nagylzs/runtree` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nagylzs/runtree"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
